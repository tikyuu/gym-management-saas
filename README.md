# Gym Management SaaS

パーソナルジム向けマルチテナント会員・予約管理SaaSを題材に、APIとAWSインフラの設計・実装・運用を学ぶポートフォリオです。

## 今回の範囲

- FastAPI、PostgreSQLのテーブル・マイグレーション、開発環境向けAWS CDK
- コンテナ、CI/CD、認証・権限、ログ・監視、障害対応の設計と検証

Reactフロントエンドと本番環境の構築は今回の完成範囲に含めません。画面を備えたSaaSとしての公開や、Kubernetes・AIインフラの実装は今後の別工程とします。

## 検証状況

コード・ローカル環境・CIでの検証を進めています。AWS上でシステム全体が稼働することは、まだ確認していません。
